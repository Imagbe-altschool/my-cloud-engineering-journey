# Linux File Permissions

## Checking Permissions

I used `ls -l` to view file permissions.

```bash
ls -l
```
# Changing Permissions
I used `chmod` to modify file permissions.

```bash
chmod 755 file.txt
```
# Changing Ownership
I used `chown` to change ownership.

```bash
sudo chown user:group file.txt
```
## What I Learned
Linux permissions determine what the owner, group,
and other users can do with a file or directory.
